{# =========================================================================== TABELLA DATI QUANDO SI USA. Per ogni elenco di righe con piu' di una colonna: prodotti, documenti, progetti, utenti, messaggi. E' il componente che in Aurora si guarda piu' a lungo di tutti, quindi e' quello su cui vale la pena essere pignoli. Che cosa porta gia' fatto: - l'intestazione resta ferma mentre si scorre (thead sticky), cosi' alla riga quaranta si sa ancora che cosa si sta leggendo; - le righe si alternano di tinta; - la tabella scorre in orizzontale dentro il suo riquadro invece di allargare la pagina; - quando non c'e' niente da mostrare compare una riga sola con una frase che spiega perche', invece di una tabella vuota che sembra un guasto. L'ORDINAMENTO LO FA IL SERVER. Le intestazioni ordinabili sono collegamenti che rimettono nell'indirizzo il parametro "ordina" e il verso. Non e' una scelta di ripiego: cosi' l'elenco ordinato ha un indirizzo suo, che si mette nei preferiti e si manda a un collega, e funziona anche senza JavaScript. La rotta legge i due parametri e ordina la sua interrogazione. COME SI USA. Si passa l'elenco delle colonne e si scrivono le righe dentro il blocco: {% raw %}{% from "components/tabella.html" import tabella %} {% set colonne = [ {"etichetta": "Codice", "chiave": "codice", "classe": "colonna-codice"}, {"etichetta": "Descrizione"}, {"etichetta": "Stato"}, {"etichetta": "", "classe": "colonna-azioni"}, ] %} {% call tabella(colonne, vuota=prodotti|length == 0, messaggio_vuoto="Nessun prodotto con questi filtri.", ordina=ordina, verso=verso, indirizzo="/prodotti") %} {% for p in prodotti %} {{ p.code }} {{ p.description }} {{ etichetta_stato(p.state) }} ... {% endfor %} {% endcall %}{% endraw %} Ogni colonna e' un dizionario con: etichetta il testo dell'intestazione (obbligatorio, puo' essere vuoto) chiave se c'e', la colonna diventa ordinabile e questo e' il valore che finisce nel parametro "ordina" classe classe della cella: colonna-numero, colonna-codice, colonna-azioni titolo spiegazione che compare passandoci sopra con il mouse =========================================================================== #} {% macro tabella(colonne, vuota=false, messaggio_vuoto="Nessun risultato.", ordina=none, verso="asc", indirizzo="", riepilogo=none) -%}
